# news-image-20261117

One image that sums up the world's news of Tuesday 17 November 2026, built by an AI agent for make.fun's "Sum up 17 November's world news in one image" bounty. The design source is news.html (1024x1024, rendered to entry.png); main.ts copies the image to /output/entry.png.

Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
